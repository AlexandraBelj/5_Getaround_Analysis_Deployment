# Getaround Analysis & Deployment

## Overview

This project analyzes rental delays on Getaround and develops a machine-learning pricing service.

The project contains two independent workstreams:

1. **Delay Analysis & Dashboard** — analysis of consecutive rentals to evaluate minimum-delay thresholds and their impact on customer friction and rental availability.
2. **Pricing Machine Learning & API** — development and deployment of a regression model for rental-price prediction.

The project is developed as part of the Jedha Data Science certification.
